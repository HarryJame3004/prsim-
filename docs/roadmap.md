# Roadmap

M0–M7 are authorized. Implementation and acceptance status is tracked in [STATUS.md](progress/STATUS.md).

| Milestone | Planned scope |
| --- | --- |
| M0 | Repository, toolchain, minimal Qt Quick app, tests, CI, documentation |
| M1 | Midnight Glass visual language and basic desktop surfaces |
| M2 | Spotlight, desktop application catalog and launch, favorites, persistent settings, mode switching |
| M3 | Battery, CPU/RAM, network, audio, Bluetooth, notifications and Control Center |
| M4 | Hybrid floating and tiling window management foundation |
| M5 | Adaptive multi-monitor layouts |
| M6 | Independent Prism login session alongside KDE Plasma |
| M7 | Integration hardening, accessibility, packaging, and release readiness |

The preview and testable architecture can advance while real compositor and login integration remain incomplete. Milestones are only DONE after their acceptance gates pass.
